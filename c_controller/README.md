# Discrete PI Controller in C

基于 C 语言的离散 PI 控制器设计与数值验证。

## 1. 文件说明

| 文件                  | 功能                                |
| --------------------- | ----------------------------------- |
| pi_controller_test.c  | 位置式 PI、输出限幅与条件积分抗饱和 |
| pi_incremental_test.c | 增量式 PI 与输出限幅                |
| pi_comparison_test.c  | 位置式与增量式 PI 等价性验证        |

## 2. Day 2：位置式 PI

### 实现功能

- 后向矩形积分
- 位置式 PI 控制算法
- 结构体保存控制参数及积分状态
- 输出限幅（0～100）
- 条件积分抗饱和

### 测试结果

| 测试工况        | 最终积分 | 最终输出 |
| --------------- | -------: | -------: |
| 正向饱和        |       40 |      100 |
| 负向饱和        |      -40 |        0 |
| 误差反向，第1次 |      140 |      100 |
| 误差反向，第2次 |      130 |      100 |
| 误差反向，第3次 |      120 |      100 |
| 误差反向，第4次 |      110 |       90 |

## 3. Day 3：增量式 PI

### 实现功能

- 增量式 PI 控制算法
- 历史误差与历史输出状态管理
- 输出限幅（0～100）
- 位置式与增量式 PI 对比测试

### 控制参数

- Kp = 2
- Ki = 1
- Ts = 0.01 s
- Target = 1000

### 测试结果

| 次数 | 误差 | 位置式（无限幅） | 增量式（无限幅） | 增量式（有限幅） |
| ---- | ---: | ---------------: | ---------------: | ---------------: |
| 1    |  200 |            402.0 |            402.0 |            100.0 |
| 2    |  150 |            303.5 |            303.5 |              1.5 |
| 3    |  100 |            204.5 |            204.5 |              0.0 |
| 4    |  120 |            245.7 |            245.7 |             41.2 |
| 5    |   90 |            186.6 |            186.6 |              0.0 |

### 实验结论

1. 在控制参数、输入序列、积分方法和初始状态一致，
   且不存在限幅等非线性处理时，
   位置式与增量式 PI 在数学上等价。

2. 位置式 PI 需要保存累计积分状态，
   增量式 PI 需要保存历史误差和历史输出。

3. 增量式 PI 的历史输出保存方式会影响饱和后的控制行为。

4. 条件积分抗饱和可以阻止积分状态进一步加重输出饱和，
   同时允许积分向解除饱和的方向变化。
