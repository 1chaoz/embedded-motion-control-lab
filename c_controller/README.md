## 2. Day 2：位置式 PI

### 实现功能

- 后向矩形积分
- 位置式 PI 控制算法
- 结构体保存控制参数及积分状态
- 输出限幅（0～100）
- 条件积分抗饱和

| --------------- | -------: | -------: |
| 正向饱和        |       40 |      100 |
| 负向饱和        |      -40 |        0 |
| 误差反向，第1次 |      140 |      100 |
| 误差反向，第2次 |      130 |      100 |
| 误差反向，第3次 |      120 |      100 |
| 误差反向，第4次 |      110 |       90 |

## 3. Day 3：增量式 PI

### 实现功能

- 增量式 PI 控制算法
- 历史误差与历史输出状态管理
- 输出限幅（0～100）
- 位置式与增量式 PI 对比测试

### 控制参数

- Kp = 2
- Ki = 1
- Ts = 0.01 s
- Target = 1000

### 测试结果

| 次数 | 误差 | 位置式（无限幅） | 增量式（无限幅） | 增量式（有限幅） |
| ---- | ---: | ---------------: | ---------------: | ---------------: |
| 1    |  200 |            402.0 |            402.0 |            100.0 |
| 2    |  150 |            303.5 |            303.5 |              1.5 |
| 3    |  100 |            204.5 |            204.5 |              0.0 |
| 4    |  120 |            245.7 |            245.7 |             41.2 |
| 5    |   90 |            186.6 |            186.6 |              0.0 |

### 实验结论

1. 在控制参数、输入序列、积分方法和初始状态一致，
   且不存在限幅等非线性处理时，
   位置式与增量式 PI 在数学上等价。

2. 位置式 PI 需要保存累计积分状态，
   增量式 PI 需要保存历史误差和历史输出。

3. 增量式 PI 的历史输出保存方式会影响饱和后的控制行为。

4. 条件积分抗饱和可以阻止积分状态进一步加重输出饱和，
   同时允许积分向解除饱和的方向变化。

## 4. Day 4：C语言闭环PI控制仿真

### 实验内容

1. 使用前向欧拉法，将一阶惯性环节离散化。
2. 使用 C 语言实现一阶被控对象模型。
3. 实现位置式 PI 控制器。
4. 将 PI 控制器与被控对象连接，搭建完整的闭环控制系统。
5. 使用二维数组和嵌套循环，实现 PI 参数自动扫描。
6. 比较不同 PI 参数下的系统响应。

### 被控对象

$
G(s)=\frac{1}{0.5s+1}
$

采用前向欧拉法离散化：

$
y[k+1]=0.98y[k]+0.02u[k]
$

### 实验参数

| 参数        | 数值   |
| ----------- | ------ |
| 时间常数 τ  | 0.5 s  |
| 采样周期 Ts | 0.01 s |
| 目标值      | 1.0    |
| 仿真时间    | 10 s   |

### PI参数对比

| 实验组 | Kp   | Ki   |
| ------ | ---- | ---- |
| A组    | 1    | 1    |
| B组    | 2    | 1    |
| C组    | 2    | 4    |
