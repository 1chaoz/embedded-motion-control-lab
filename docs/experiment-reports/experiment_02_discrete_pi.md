# Day 2：离散 PI 控制器（C语言）

## 功能

- 位置式 PI 控制算法
- 输出限幅（0～100）
- 条件积分抗饱和
- 三种工况的数值测试

## 测试

| 测试工况          | 预期积分 | 预期输出 |
| ----------------- | -------: | -------: |
| 正向饱和          |       40 |      100 |
| 负向饱和          |      -40 |        0 |
| 误差反向（第4次） |      110 |       90 |

三组基础测试已在在线 C 编译器中运行通过。

## 说明

本程序用于学习离散 PI 算法，尚未在 STM32 或实际电机上进行闭环验证。
